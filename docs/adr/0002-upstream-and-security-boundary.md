# Оригинальный Hermes и стандартные механизмы Kubernetes

По ответам первого раунда оператор является самостоятельным продуктом и запускает оригинальный Hermes без изменений исходного кода. Предпочтителен официальный образ; собственная сборка, например `wbe7/hermes`, допустима, если официального образа нет. Если требование нельзя выполнить без изменения upstream, это выносится на отдельное обсуждение, а не реализуется скрытым patchset.

Для изоляции используются стандартные механизмы Kubernetes без обязательных Kata/gVisor и без отдельного сервиса сокрытия credentials. Пользователь выбрал эту границу ради простоты: credentials выделены конкретной инсталляции и могут быть прочитаны из неё. Контейнерное ограничение привилегий и сетевые политики не должны документироваться как абсолютная гарантия от container escape или доступа к любому адресу инфраструктуры при любой реализации сети.
