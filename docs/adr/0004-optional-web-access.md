# Опциональный штатный Web и готовая Gateway-инфраструктура

По ответам пользователя от 2026-09-28 инсталляция может иметь Telegram, Web, оба
канала или ни одного. Web выключен по умолчанию. Используется полный штатный
dashboard Hermes и его авторизация; собственный интерфейс или внешний auth proxy
не добавляются. Пароль/секретные значения доступны в основном Secret инсталляции:
используются заданные или генерируются отсутствующие, остальные ключи сохраняются.

Поддерживаются отдельные поддомены и пути общего домена. Пользователь принял,
что Path не создаёт изоляцию browser origins: для разных недоверенных клиентов
рекомендуются поддомены, Path — для одной доверенной группы. Переписывание upstream
ради дополнительной браузерной изоляции не входит в этот вариант решения.

DNS, сертификаты и Gateway остаются под управлением инфраструктуры. Оператор
создаёт Service, HTTPRoute и сетевые правила, ссылаясь на готовый HTTPS listener.
Это сохраняет разделение прав между администратором инсталляции и владельцем
общей инфраструктуры и не привязывает оператор к конкретному DNS/TLS-провайдеру.

Поддерживаются внутренние и внешние Gateway. Для публичного доступа пользователь
выбрал штатную авторизацию после сообщения о рекомендации upstream ограничивать
password provider доверенной сетью/VPN. Это ограничение документации Hermes должно
быть явно отражено в руководстве; оператор не обещает MFA или отдельные web-аккаунты.
