# API Hermes Operator

Первоначальное предложение уточнено после завершения интервью. Актуальный контракт находится в [спецификации v1alpha1](v1alpha1.md), установка и эксплуатация — в [deployment contract](deployment.md), последовательность работ — в [плане реализации](../superpowers/plans/2026-09-18-hermes-operator.md).

Документы описывают предстоящую реализацию; опубликованного CRD и подтверждённой runtime-совместимости пока нет. История продуктовых решений сохранена в [интервью](interview.md) и [ADR о конфигурации](../adr/0001-declarative-configuration-authority.md).
