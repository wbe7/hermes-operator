# STT Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Declaratively configure remote STT with independent LLM URL/key inheritance and prove Russian transcription on the existing smoke installation.

**Architecture:** Extend the existing typed API, validation, secret binding and startup bundle. Reuse revision rollout and startup restoration; do not change upstream Hermes or introduce a second transcription service.

**Tech Stack:** Go, controller-runtime, Kubernetes CEL/CRD, Python runtime tests, Helm, pinned Hermes v2026.9.14.

**Spec:** [STT contract](../../design/stt.md).

## Global Constraints

- STT disabled unless enabled; language ru; echoTranscripts true.
- URL and Secret reference inherited independently; explicit missing key never falls back.
- Auth Inherit/APIKey/None; None uses an SDK placeholder, no real credential.
- Keep namespace-local Secrets and existing PVC/user state; no upstream patches.
- Smoke only hermes-smoke in berger-apps; Telegram interaction only @HermesOperatorK8SBot.
- Authorized LiteLLM change adds qwen3-asr-1.7b to the existing test key only, retaining other fields/models.

## Review Focus

- Separate URL override must preserve exactly the selected key, including custom primary references.
- Old PVC aliases and stored STT selection must not defeat disabled state or explicit provider.
- Disabled STT must not require an unused Secret or alter unrelated credentials.
- Inherit with model.auth None and explicit STT key must select APIKey; explicit APIKey without any key source must reject.
- Removing STT and changing language to auto must clear previous effective configuration while preserving user files/history.
