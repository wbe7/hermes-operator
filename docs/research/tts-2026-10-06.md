## Hermes

Закреплённый Hermes: v2026.9.14, revision
`345cd2b057a452236de401d3534b8502a7465e8d`.

- OpenAI-compatible backend принимает model/base_url/api_key/voice/speed.
  Voice по умолчанию alloy. Language уходит как `extra_body.lang_code`;
  instructions берётся из вызова инструмента, а не из tts.openai.instructions.
  Speed 1.0 не отправляется; прочие значения ограничиваются 0.25–4.
  [Backend](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/tts_tool_openai.py).
- Реального выключателя tts.enabled нет. Unknown provider не является безопасным
  способом выключения: dispatcher может выбрать Edge/NeuTTS. Нужно согласовать
  выключение toolset tts с автоответами и сохранёнными режимами; use_gateway=false
  исключает старый выбор managed Nous. При явном OpenAI failure другой провайдер
  автоматически не выбирается.
  [Tool dispatch](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/tts_tool.py).
- /voice хранит off/voice_only/all в gateway_voice_mode.json по ключу чата.
  voice_only означает ответы на входящие голосовые, all — на все сообщения.
  Chat mode имеет приоритет над voice.auto_tts. Последний сам по себе не задаёт
  глобальный voice_only: fallback озвучивает также текстовые ответы.
  [Gateway](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/gateway/run_voice.py).
- Формат выбирается штатным delivery path; для Telegram используется Opus.
  Текст сохраняется подписью при длине до 1024 символов, иначе отдельным
  сообщением; при ошибке синтеза сохраняется текстовый ответ. Эти утверждения
  основаны на исходниках, сквозная доставка в Telegram ещё не проверена.

## Настроенный Fish / LiteLLM

- Alias `fish-s2-pro`, router target `openai/fish-s2-pro`.
- Внутренний backend: сервис fish-s2-pro-vllm-predictor, namespace infra-inference,
  OpenAI-compatible `/v1`. Внешнее подключение планируется через существующий
  `https://inference.s2technologies.ru/v1`.
- Revision модели: `1de9996b6be38b745688de084d87a5633f714e4e`.
- GET /v1/audio/voices вернул voices=[default], uploaded_voices=[]. Route-level
  defaults голоса в LiteLLM нет. Fish не предоставляет встроенный alloy:
  serving_speech нормализует default в пустой reference, а Fish adapter отклоняет
  неизвестные ненулевые voice IDs. Загрузка голоса требует отдельной регистрации.
- Схема сервера поддерживает mp3/opus/wav/pcm/flac и speed 0.25–4.
  Fish adapter не использует языковую подсказку Hermes lang_code. Это анализ
  схемы/исходников, а не доказательство качества или успешного синтеза.
- /key/info подтвердил отсутствие fish-s2-pro в allowlist существующего dedicated
  smoke key. Никакие права ключа в ходе исследования не менялись.

Окончательная приёмка должна отдельно доказать реальный ответ /audio/speech,
корректный audio container/длительность, native Hermes synthesis, выбранные режимы
автоответа и восстановление после рестарта. Успех прямого API не заменяет
проверку доставки голосового в разрешённый Telegram-чат.
