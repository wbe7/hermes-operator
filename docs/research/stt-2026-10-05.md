## Подключение к OpenAI-compatible STT

Hermes поддерживает `stt.enabled`, `stt.provider: openai` и вложенные
`stt.openai.model`, `base_url`, `api_key`. SDK отправляет запрос
`audio.transcriptions.create`; для `qwen3-asr-1.7b` выбирается JSON-ответ с текстом.
Это позволяет использовать указанный LiteLLM endpoint без изменения upstream.
[Backend](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_cloud.py#L107-L165).

Наследование URL и ключа из основной LLM-секции оператор должен выполнить сам.
В upstream публичный `stt.openai.base_url` без вложенного `api_key` может быть
потерян на следующей ступени выбора credentials: env-ключ разрешается вместе с
`STT_OPENAI_BASE_URL` либо стандартным URL OpenAI. Следовательно, startup config
должен получать одновременно эффективный URL и ссылку на эффективный credential.
Это вывод из кода, а не результат сетевого smoke.
[Resolver](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_cloud.py#L366-L418).

Без ключа upstream допускает локальный/private endpoint, подставляя непустое
служебное значение для SDK. Для публичного адреса отсутствие ключа вызывает
ошибку. Поддержка операторского `auth: None`, если она потребуется, должна
документировать возможный служебный Authorization header; это не гарантия
полного отсутствия заголовка.
[Keyless endpoints](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_cloud.py#L351-L377).

## Defaults, язык и восстановление конфигурации

- Upstream включает `stt.enabled` и `stt.echo_transcripts`, задаёт глобальный
  `stt.language: en`; провайдер может выбираться автоматически. Поэтому отсутствие
  новой секции CR нельзя молча приравнять к прежнему выключенному STT.
  [Defaults](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/hermes_cli/config_defaults.py#L1070-L1105).
- Язык разрешается как первое непустое значение: provider language, общий STT
  language, `HERMES_LOCAL_STT_LANGUAGE`, затем автоопределение. Строка `auto` не
  является специальным значением. Для управляемого автоопределения нужно очистить
  обе конфигурационные подсказки и соответствующую env-подсказку, включая старые
  значения с PVC. Для явного языка — восстановить согласованное значение.
  [Language resolver](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_tools.py#L93-L107).
- Legacy top-level `stt_enabled` и `stt_echo_transcripts` перекрывают вложенную
  секцию при чтении gateway config. Typed STT требует учитывать и эти aliases
  при проверке конфликтов и восстановлении после рестарта.
  [Gateway config](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/gateway/config.py#L670-L714).

## Голосовые сообщения и вложения

Автоматическая gateway-транскрибация отличается от обработки файла агентом.
Нативные voice messages Telegram проходят STT, но `MessageType.AUDIO` и
`DOCUMENT` исключены из автоматической ветви; вложения остаются файлами для
последующей работы агента. Обещать автоматическое распознавание любого аудиофайла
по наличию STT-настроек нельзя.
[Gateway classification](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/gateway/run.py#L2431-L2436).

Выбор явного cloud provider не означает полного отсутствия fallback: после
ошибки remote STT gateway отдельно пробует уже установленный локальный backend.
Этот путь не устанавливает Python-зависимости, но установленный faster-whisper
может загрузить модель. Оператор сохраняет границу неизменённого upstream.
[Gateway recovery](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/gateway/run_inbound.py#L1930-L1940),
[Local fallback](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_tools.py#L530-L541).

## Ограничения и зависимости

- OpenAI SDK timeout — 30 секунд, `max_retries=0`; эти значения зашиты в backend.
  Есть отдельная повторная попытка после перекодирования при некоторых ответах
  HTTP 400 о формате файла. Новый параметр CR не сможет изменить фиксированный
  timeout без дополнительной поддержки upstream.
  [Client construction](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_cloud.py#L39-L64).
- Remote upload cap — 25 MiB; стандартный Telegram download cap — 20 MiB.
  [STT constants](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/tools/transcription_common.py#L32-L34),
  [Telegram download](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/plugins/platforms/telegram/adapter.py#L4699-L4705).
- `openai` входит в базовые Python-зависимости, официальный Dockerfile
  устанавливает ffmpeg. `faster-whisper` относится к optional voice extra;
  наличие локального backend в конкретном пользовательском home нельзя выводить
  только из Dockerfile. Проверка runtime остаётся частью приёмки.
  [Dependencies](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/pyproject.toml),
  [Image build](https://github.com/NousResearch/hermes-agent/blob/345cd2b057a452236de401d3534b8502a7465e8d/Dockerfile).

## Предварительная проверка LiteLLM

Существующий `MODEL_API_KEY` smoke-инсталляции разрешил `GET /v1/models` (HTTP
200), но результат не содержал `qwen3-asr-1.7b`. Значение ключа не выводилось.
Список моделей сам по себе не доказывает запрета endpoint, поэтому следом выполнен
`POST /v1/audio/transcriptions` с коротким WAV, синтезированным локально голосом
Milena: «Это проверка распознавания речи. Номер теста сорок два.» Переданы
`model=qwen3-asr-1.7b`, `language=ru`, `response_format=json`.

Результат — HTTP 403 `key_model_access_denied`: текущий ключ допускает только
`qwen38-27b`, `qwen38-27b-xhigh`, `qwen3-embedding-8b`. Это уже реальное
подтверждение недостаточного разрешения ключа, а не вывод из `/models`.
Перед успешной приёмкой нужно разрешить ему также `qwen3-asr-1.7b`.
Права LiteLLM, модель и Secret в рамках исследования не изменялись.
